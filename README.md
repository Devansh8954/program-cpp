## 🚀 Getting Started

### Prerequisites

- **GCC / G++** with C++17 support
- VS Code (with C++ extension) or any IDE

### Compile & Run

```bash
# Clone the repository
git clone https://github.com/Devansh8954/program-cpp.git
cd program-cpp

# Compile any program
g++ -std=c++17 -o output calculator.cpp
./output

# Compile with all warnings
g++ -std=c++17 -Wall -Wextra -o output factorial.cpp && ./output
```

## 💡 Key Concepts Covered

- ✅ **C++ Fundamentals** — Variables, loops, functions, recursion
- ✅ **OOP Principles** — Encapsulation, inheritance, polymorphism, abstraction
- ✅ **STL Containers** — `vector`, `map`, `unordered_map`, `set`, `stack`, `queue`
- ✅ **Algorithm Design** — Divide & conquer, greedy, dynamic programming
- ✅ **Hashmaps** — Frequency counting, two-sum patterns, anagram detection
- ✅ **DSA** — Linked lists, trees, sorting, searching
- ✅ **Pattern Programs** — Logic building for nested loops
- ✅ **Math Algorithms** — GCD, prime sieve, power, combinations
